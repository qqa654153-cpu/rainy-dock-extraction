# 暴雨夜码头 · 战术撤离行动 (Rainy Dock Extraction)

**在线试玩（GitHub Pages）：** https://qqa654153-cpu.github.io/rainy-dock-extraction/

> 渗透至被机器军团控制的 04 号集装箱码头。任意顺序切断 3 处通信中继器，守住撤离倒计时后前往东北泊位登船撤离。

## 游戏特色

- **纯前端 3D WebGL / Three.js 战术射击**：免构建、免后端，打开网页即可游玩；支持 4 档画质预设（低 / 中 / 高 / 极限画质，含 SSR/GTAO、动态投影、体积雾、高模与 AgX）及动态分辨率保护（DRS）。
- **多模式玩法**：
  - **新手教程**：快速上手战术移动、潜行与武器操作。
  - **实战撤离**：渗透 04 号码头，切断 3 处通信中继器并坚持到撤离点登船。
  - **训练模式**：包含 **限时模式**（30 / 60 / 90 秒安全靶场冲刺，击中红核触发暴击秒杀与连击倍率）、**无尽模式**（真实波次生存与每波三选一战术空投增益）以及 **关卡练习**（6 大战术战区自由选关，支持无伤练路线开关）。
- **4 档难度与挑战词缀**：支持 **新兵护航 / 标准行动 / 老兵特遣 / 拟真夜战（硬核无准星）**，并可叠加 **全图停电 (+20%)**、**高爆狂潮 (+15%)**、**精锐巡防 (+25%)** 挑战词缀提升评分倍率。
- **武器配装与战术系统**：主武器可选 **CAR-47 卡宾枪**、**MK-14 DMR**、**M890 破门霰弹**，标配副武器 **消音 USP-9**；支持消音器热装卸、背刺处决、投掷物抛物线预瞄、战术扫描与可解锁枪械涂装（夜幕幽灵、海军蓝 HAZMAT）。
- **中文神经语音电台**：内置离线语音包（`voices/voice_pack.js`），支持战术对讲机滤波与清晰原声模式。

## 操作指南

| 按键 | 功能说明 |
| --- | --- |
| `W` `A` `S` `D` | 移动 |
| `Shift` / `C` / `Shift + C` | 冲刺 / 下蹲 / 滑铲 |
| `鼠标左键` / `鼠标右键` | 开火 / 开镜（靠墙自动探头，可在设置中切换 Toggle ADS） |
| `R` | 换弹 |
| `1` / `2` | 切换主武器 / 副武器 |
| `T` | 消音器热装卸 |
| `F` | 开关枪灯 |
| `按住 G` / `4` | 抛物线预瞄并投掷（右键取消）/ 切换投掷物 |
| `Q` / `V` | 战术扫描 / 近战与背刺处决 |
| `E` | 交互（靠近中继器按 `G` 可贴 C4 强破） |

## 本地运行

由于项目采用纯静态前端架构且无构建步骤，可直接在仓库根目录启动任意静态服务器进行本地体验：

```bash
python -m http.server 8080
```

然后在浏览器访问 `http://localhost:8080/`（或直接双击打开 `index.html`）。
